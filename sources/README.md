# Editable sources for generated assets

Editable visual, input, and audio sources are included here. The generated
OpenPCW-OS directory carries the original integration JSON, source identity
and manifests, licences, provenance, and the tool for rebuilding its embedded
resources from a matching standalone source tree. Normal core builds use the
generated headers already present and remain offline.
See [mappings](mappings/README.md), [FDC sound](fdc/README.md), and
[OpenPCW-OS reconstruction](openpcw-os/SOURCE.md).
